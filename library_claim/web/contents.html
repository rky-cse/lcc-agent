Select a saved view, then click two opposite corners of the visible object. No object is saved by clicking.

Label format and source choices
{"field":"category","value":"chair","basis":"visible_appearance","statement":"Visible chair in the selected original"}
Fields: category, description, material, brand, model. Brand/model require visible_marking and literal reviewed text. Other bases: visible_appearance or claimant_assertion. Omit unreadable fields.
Art: original / print / unknown plus a literal claimant statement. Optional guidance_revision + declaration_index bind to a saved voice declaration.
Group: parent classified furniture_set, distinct member IDs and set / components counting_basis.
Measure: one existing M03 planar face request, item ID as annotation ID, and distinct height_axis / width_axis. Each field stays unknown without its own valid proof.

Use reviewed_comparable for a range. It requires matched category, material, verified requested size axes, sufficient distinct listings/domains and a declared tolerance. Policy values remain required choices; amounts and tolerances should be decimal strings.
